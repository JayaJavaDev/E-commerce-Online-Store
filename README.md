# ZENVORA MART

### Elevate Your Everyday

Zenvora Mart is a responsive e-commerce website built using React.

## Features

- Dynamic product listing using map()
- Reusable React components
- Product details
- Shopping cart functionality
- Increase and decrease product quantity
- Dynamic price calculation
- Responsive user interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- JSON

## Getting Started

Install dependencies:

npm install

Run the project:

npm run dev
